# Rubi guide

Rubi is a multi-purpose SimpleX Chat bot: utilities, web lookups, Reddit and X posts, polls, reminders, games and
group moderation in one bot. This guide explains how to use it, whether you're chatting with Rubi, running a group,
or operating your own copy.

## Quick start

1. Connect to Rubi with its SimpleX address. Someone who already talks to Rubi can send `/invite` to get the link and
   a QR code.
2. Send `/help`. Rubi lists the commands you can use in that chat.
3. Send `/help <command>` (for example `/help remind`) to see everything about one command.

In a group, the same commands work. Ask an owner to add Rubi (see the [group admin guide](group-admins.md)).
